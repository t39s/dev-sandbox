# Исследование UI аналогичных игр

## Задача

Найти интерфейсный паттерн, который позволит объединить три варианта одной и той же игры без отдельного экрана настроек и без визуального перегруза.

## Наблюдения

### 1. Варианты лучше описывать парой «размер + условие победы»

XO Classic показывает выбор поля карточками, где одновременно указаны `3×3`, `4×4`, `5×5` и число символов подряд. Это важно для нашей задачи: одного размера недостаточно, поскольку существуют два разных режима `4×4`.

Источник:
https://risustech.dev/en/apps/xo-classic/

### 2. Переключатель режима может жить прямо в игровом экране

Evergreen Arcade размещает выбор размера поля рядом с текущей игрой вместе с другими параметрами. Это сокращает путь «сменить вариант → снова играть» и не требует меню.

Источник:
https://evergreenarcade.com/tic-tac-toe/

### 3. Минималистичные версии оставляют только поле, статус и перезапуск

Примеры минимальных интерфейсов показывают устойчивую композицию: заголовок → поле → статус/основное действие. Дополнительные настройки полезны только тогда, когда они не вытесняют поле из центра внимания.

Источники:
- https://simpledevstudio.itch.io/tic-tac-toe
- https://crazygames-poki.com/Puzzle/simple-tic-tac-toe

### 4. Много размеров не требует визуально тяжёлого меню

Современные версии Tic-Tac-Toe часто поддерживают 3×3, 4×4 и более крупные поля. Сам факт нескольких размеров стал обычным продуктовым паттерном; ценность интерфейса определяется тем, насколько быстро пользователь понимает различия правил.

Источники:
- https://play.google.com/store/apps/details?id=com.crypto.tictactoe
- https://play.google.com/store/apps/details?hl=en&id=vladyslavpohrebniakov.justtictactoe

## Выводы для ttt

Выбран подход:

1. Один экран без модальных стартовых меню.
2. Нативный сегментированный переключатель из трёх вариантов над полем.
3. Каждый сегмент содержит две строки:
   - размер поля;
   - количество символов подряд.
4. Под переключателем — одна короткая строка о свойствах алгоритма текущего режима.
5. Поле, статус и кнопка «Новая игра» не меняют своего положения.
6. Счёт адаптируется к режиму:
   - `3×3 / 3`: только достижимые метрики `Ничьи / Алгоритм`;
   - оба режима `4×4`: `Вы / Ничьи / Алгоритм`.
7. Смена режима начинает новую партию, но не сбрасывает накопленный счёт режима.

## Почему не выбран отдельный экран Setup

Карточный Setup хорошо масштабируется на большое число параметров, но для трёх заранее определённых вариантов добавляет лишний шаг. В нашем приложении минимализм и быстрый переход между вариантами важнее расширяемого меню настроек.
