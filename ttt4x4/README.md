# ttt 0.5.0

Один минималистичный интерфейс для трёх разработанных вариантов «Крестиков — Ноликов»:

1. `3×3` — 3 подряд, точный алгоритм;
2. `4×4` — 4 подряд, глубинный Alpha–Beta;
3. `4×4` — 3 подряд, точный алгоритм.

## Интерфейс

Режим выбирается сегментированным переключателем над полем. Отдельный экран настроек не используется.

Счёт хранится независимо для каждого варианта с использованием прежних ключей `localStorage`, поэтому существующая статистика совместима с объединённой версией.

## Запуск

Откройте `index.html` в браузере.
