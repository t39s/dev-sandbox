# random_timer

Разработчик:
ChatGPT (AI-ассистент в голосовом интерфейсе;
модель: GPT-5.6 Sol; интеллект: средний или высокий)


`random_timer` — автономный случайный таймер с настраиваемыми паузами и звуковым сигналом. Приложение предназначено для тренировок, упражнений и других сценариев, в которых действие должно начинаться после случайной задержки.

Текущая стабильная версия: **0.11.12**.

## Возможности

- запуск и остановка таймера одной большой кнопкой;
- случайный выбор паузы без повторений до завершения текущего цикла;
- отображение последнего выбора, уже выбранных пауз и остатка цикла;
- собственный список пауз с поддержкой секунд, минут и множителей;
- отдельные режимы просмотра и редактирования списка пауз;
- проверка черновика до применения без изменения действующих настроек;
- именованные наборы настроек для разных упражнений и сценариев;
- пять типов синтезируемого сигнала и регулировка громкости;
- сохранение настроек в браузере;
- выбор случайных значений через Web Crypto без резервного перехода на `Math.random()`;
- работа без сборки, сервера и внешних зависимостей.

## Быстрый запуск

1. Скачайте [random_timer_0.11.12.html](random_timer_0.11.12.html).
2. Откройте файл в современном браузере либо разместите его на статическом веб-сервере.
3. Нажмите «Настройки», чтобы выбрать набор, сигнал, громкость и список пауз.
4. Вернитесь на главный экран и нажмите «Включить».

Все стили, разметка и JavaScript находятся внутри одного HTML-файла. Установка пакетов и отдельный процесс сборки не требуются.

## Основной сценарий

После нажатия «Включить» приложение выбирает одну паузу из оставшихся в текущем цикле, запускает обратный отсчёт и затем воспроизводит выбранный сигнал. Повторное нажатие останавливает текущий отсчёт или сигнал.

В пределах цикла логические экземпляры пауз не повторяются. После использования всех экземпляров следующий случайный выбор автоматически начинает новый цикл. Цикл можно сбросить вручную с подтверждением.

## Формат списка пауз

Паузы разделяются запятыми или переводами строки:

```text
2s, 5s, 10s, 2m30s
```

Поддерживаются:

- секунды: `15s`;
- минуты: `2m`;
- минуты и секунды: `2m30s` или `2m 30s`;
- множитель количества экземпляров: `5s*3`;
- исключение значения без удаления строки: `10s*0`.

Редактор хранит изменения как черновик. Действующий список меняется только после успешной проверки и нажатия «Сохранить». Некорректный или неприменённый черновик не влияет на таймер и текущий цикл.

## Наборы настроек

Набор включает применённый список пауз, тип сигнала и громкость. Наборы можно создавать, открывать и удалять; активный набор удалить нельзя.

Сохранённые наборы доступны окнам и вкладкам того же сайта, а выбор активного набора относится к конкретной вкладке. Изменения из другого окна не подменяют активные настройки автоматически: приложение проверяет актуальность данных и предупреждает о конфликте.

## Совместимость и ограничения

Подтверждённый рабочий сценарий:

- Safari на iPad;
- два одновременно видимых окна;
- оба окна остаются на экране;
- автоблокировка экрана отключена;
- пользователь не переключается в другую вкладку или приложение во время отсчёта.

Приложение не обещает точную работу таймера или звука в фоне, после блокировки экрана либо при выгрузке страницы браузером. Мобильные браузеры могут ограничивать таймеры и аудио неактивных страниц. Для запуска звука может потребоваться действие пользователя.

Для случайного выбора требуется `crypto.getRandomValues()`. Если Web Crypto недоступен, приложение сообщает об ошибке и не использует `Math.random()` как скрытую замену.

## Хранение данных и приватность

После загрузки приложение не обращается к внешним сервисам. Наборы и настройки сохраняются средствами браузера в `localStorage`, а активный набор вкладки — в `sessionStorage`.

Данные не синхронизируются между устройствами. Очистка данных сайта или хранилища браузера удалит сохранённые настройки.

## Стабильная база разработки

Все новые версии создаются только из принятого файла `random_timer_0.11.12.html`. Отклонённые кандидаты не используются как исходная база и не публикуются как стабильные релизы.

Ключевые инварианты проекта:

- область просмотра списка пауз и редактор остаются разными элементами;
- черновой и применённый списки не смешиваются;
- Web Crypto сохраняется без fallback на `Math.random()`;
- UI-изменения не должны незаметно менять таймер, цикл или сигнал;
- сначала определяются сценарии и план, затем изменяется код;
- версии выпускаются небольшими тематически цельными изменениями.

Подробная история принятых версий находится в [VERSIONS.md](VERSIONS.md).
