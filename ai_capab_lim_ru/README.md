# Возможности и ограничения ИИ — русская адаптация

Самодостаточный локальный мини-сайт: главная страница, 13 уроков, интерактивный итоговый тест и страница завершения.

## Запуск
Откройте `index.html` в современном браузере. Интернет не нужен, кроме ссылки на оригинальный курс Claude Academy.

## Прогресс
Отметки о пройденных уроках и результат теста хранятся в `localStorage` браузера.

## Примечание
Это неофициальная адаптация. Текст изложен самостоятельно по мотивам структуры и публично доступных описаний курса; это не дословный перевод и не официальный материал Anthropic.
