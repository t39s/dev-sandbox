# c07a — Наблюдения Сергея Астахова о тренировках в Китае

Мобильная веб-версия статьи «Об особенностях тренировочного процесса китайских спортсменов»: Сергей Астахов, журнал «Настольный теннис», № 3 (38), 2008, с. 32–35. Автор документирует практику китайских тренеров, а не собственную методику.

## Использование

Открыть `index.html` в браузере. Страница автономна: CSS, JavaScript и все схемы встроены в один HTML, сетевые запросы не нужны.

- В статье представлены 15 технико-тактических упражнений (Приложения 1 и 2). В свёрнутом виде карточка показывает только название; нажатием раскрываются описание и кнопка «Схема + описание».
- Кнопка «Оглавление» в заголовке открывает три пункта: «Упражнения 1 мячом», «Упражнения с БКМ», «ОФП и СФП». Пункты сразу открывают режим упражнений, не прокручивая статью.
- Приложение 1 содержит четыре упражнения, Приложение 2 — одиннадцать. Переходы «Назад»/«Далее» не пересекают границу между приложениями.
- Для технико-тактических упражнений схема занимает верхнюю треть экрана и остаётся видимой, а описание прокручивается независимо ниже.
- Для Приложения 3 (ОФП и СФП) есть отдельный полноэкранный текстовый режим: шесть упражнений в игровом зале и девять на тренажёрах, без вымышленных схем.
- Режим просмотра открывается и по прямым ссылкам `#ex-app1-1` … `#ex-app2-11`, `#ex-physical-1` … `#ex-physical-15`.

## Источник

Основа — предоставленные фотографии страниц 32–35 печатной статьи. Текст в публикации сохранён без методических дополнений. Основной экран статьи и режим упражнений — разные способы просмотра одного материала.
