# c07a — Сергей Астахов: тренировочный процесс китайских спортсменов

Мобильная HTML-версия статьи Сергея Астахова («Настольный теннис», № 3 (38), 2008, с. 32–35).

Открыть: `index.html`. Приложения 1 и 2 включают 15 упражнений в режиме одновременного просмотра схемы и описания: схема занимает 1/3 видимой высоты экрана, остальное — прокручиваемый текст и постоянно доступная навигация. Все изображения встроены, интернет и сервер приложений не требуются.

Навигация: кнопки «Назад», «Далее», «Закрыть». На компьютере — Escape и стрелки. Прямая ссылка на упражнение: `#ex-app1-1` … `#ex-app2-11`.

Источник: предоставленные владельцем фотокопии печатной статьи, страницы 32–35. Контент воспроизведён из этих снимков, без редакторской адаптации тренировочной методики. Для публикации на GitHub Pages нужна конфигурация Pages с ветки `main` (корневой каталог).
