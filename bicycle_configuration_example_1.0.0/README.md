# Велосипед «Будни»: управление конфигурацией с помощью GitHub

Учебный комплект 1.0.0 • 7 сентября 2026 года

Команда проходит пять развилок: назначение велосипеда, способ получения рамы, устройство трансмиссии, привод тормозов и пересмотр трансмиссии после эксплуатации. Параллельные ветки помогают разрабатывать узлы, а проверка конфигурации выявляет несовместимость, которую Git merge не замечает.

## Начните здесь

1. [LESSON.md](LESSON.md) — основной рассказ: пять эпизодов, исследования, решения и карточки PR.
2. [PRACTICE.md](PRACTICE.md) — как выполнить этот процесс в GitHub и разобрать локальную историю; есть вопросы и ответы.
3. [snapshot/README.md](snapshot/README.md) — текущие записи велосипедной команды, доступные без Git.

## Что приложено для практики

- [bicycle-demo.bundle](bicycle-demo.bundle) — настоящий локальный Git-репозиторий с 24 commits, ветками и тегами. Сеть не нужна.
- [COMMITS.json](COMMITS.json) — точные commit ID ключевых состояний.
- [HISTORY.txt](HISTORY.txt) — текстовый вывод истории Git.
- [verify.py](verify.py) — воспроизводимая проверка конфликтов, версий, арифметики и записей экземпляра. Требуются Python 3 и Git.
- [process/GENERAL_REVIEW.md](process/GENERAL_REVIEW.md) — ревью по десяти критериям цели и границы проверенных результатов.

Люди, компоненты с суффиксом SIM, цены и физические испытания вымышлены. Git-история и результаты локальных проверок реальны. PR в рассказе смоделированы; удалённый GitHub-репозиторий не создан. Комплект иллюстрирует управление конфигурацией и не является полной производственной документацией на реальный велосипед.

## Два разных процесса

Небольшие записи в `snapshot/` принадлежат команде велосипеда внутри сюжета. Материалы в `process/` относятся к разработке самого учебного комплекта по Workkit: [исследование](process/RESEARCH.md), [план](process/PLAN.md), [исходная цель](process/OWNER_GOAL.md), [ревью](process/GENERAL_REVIEW.md), [итог цикла](process/NEXT_CYCLE_BRIEF.md). Их объём не предлагается переносить в повседневную работу маленькой велосипедной команды.

## Версии

1.0.0 — первая версия учебного комплекта. B1 / `baseline-v1` и B2 / `baseline-v2` — разные проектные конфигурации велосипеда внутри этой версии материала. `unit-built` и `unit-serviced` фиксируют записи об экземпляре, а не новые модели велосипеда.

Решение цикла разработки материала: **STOP**. Критерии постановки выполнены в пределах учебной модели; апробация на реальных учащихся не проводилась.
