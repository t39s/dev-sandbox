# «Будни»: демонстрационный репозиторий

Это настоящая локальная история Git и вымышленная история команды. PR-01…PR-07 — обозначения карточек в LESSON.md внешнего комплекта, не объекты GitHub.

main содержит последнее согласованное описание. Изготавливать разрешает release.md в принятой baseline, а факт сборки и обслуживания задаёт units/BUD-001.json.

Все артикулы и интерфейсы с суффиксом SIM вымышлены. Числовые размеры иллюстрируют согласование; подбор реальных компонентов не выполнен.

Файлы config — состав значимых узлов, не полная производственная спецификация. evidence — основания решений и проверок. Для реальной команды эти записи можно прикладывать к PR; не нужен второй пересказ в ADR.

Принятые теги не перемещаем по правилу команды; для точной идентификации сохраняем SHA commit. В учебном bundle завершённые ветки оставлены для просмотра.
