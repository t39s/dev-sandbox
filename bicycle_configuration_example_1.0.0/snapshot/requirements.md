# Исходная задача — учебные условия

R1: Мария ездит 12 км в день: асфальт, короткий участок утрамбованного гравия, подъём длиной 300 м с уклоном около 6%.
R2: Пользователь 75 кг; ежедневный груз до 8 кг; подъём должен проходиться без спешивания в комфортном для Марии темпе. Скоростная гонка не нужна; на равнине требуется привычный рабочий диапазон.
R3: Бюджет создания и первой доработки — 1000 условных единиц. Базовая сборка должна оставить резерв; электропомощь и зарядка пользователю не нужны.
R4: Мастерская закупает готовые узлы и собирает велосипед; сварки и разработки собственной рамы нет. Нужны крылья, багажник, свет и доступное мастерской обслуживание.
R5: До готовности разрешён только опытный экземпляр и программа проб. Прочность и безопасность физического велосипеда этим учебным комплектом не подтверждаются.

Числовые критерии передаточных отношений сначала остаются гипотезой; задача R2 задана с начала истории.

Уточнение по E05-field: для выбранных колёс ориентир низшей передачи ≤0.75 и высшей ≥3.2; функциональная проверка — тот же подъём с 8 кг без спешивания. Это уточнение R2, не новое назначение.
