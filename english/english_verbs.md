# Английский глагол: формы, функции и конструкции

## 1. Что такое verb

**Verb** — глагол.

Слово `verb` происходит от латинского `verbum` — «слово». Исторически термин закрепился за частью речи, которая выражает действие, процесс или состояние.

Примеры:

- `AI generates text.` — **ИИ генерирует текст.**
- `The system works.` — **Система работает.**
- `The answer is correct.` — **Ответ правильный.**

---

## 2. Как распознать глагол

В английском глагол лучше распознавать не только по значению, а по его **грамматическому поведению**.

Глагол может:

- изменять форму: `work → works → worked`;
- стоять после модального глагола: `can work`;
- образовывать инфинитив: `to work`;
- образовывать `-ing`-форму: `working`;
- образовывать Past Participle: `worked / written`;
- входить в сказуемое.

Пример:

`AI generates useful text.` — **ИИ генерирует полезный текст.**

- `AI` — noun / subject — **существительное / подлежащее**
- `generates` — verb — **глагол**
- `useful` — adjective — **прилагательное**
- `text` — noun / object — **существительное / дополнение**

Практический тест:

`can + слово`

Если слово естественно стоит после `can` в базовой форме, оно, скорее всего, глагол:

- `can generate` — **может генерировать**
- `can verify` — **может проверять**
- `can fail` — **может ошибаться / дать сбой**

---

## 3. Формы английского глагола

Для обычного смыслового глагола набор основных морфологических форм практически закрытый.

На примере `write`:

| Форма | Английский термин | Значение |
|---|---|---|
| `write` | base form | базовая форма |
| `writes` | third-person singular form | 3-е лицо ед. числа Present Simple |
| `wrote` | past form | форма Past Simple |
| `written` | past participle | причастие прошедшего времени |
| `writing` | -ing form | форма на `-ing` |

То есть:

`write → writes → wrote → written → writing`

Особый глагол `be` имеет больше форм:

`be, am, is, are, was, were, been, being`

---

## 4. V1 — base form

**V1 = базовая форма глагола.**

Примеры:

- `write` — **писать**
- `generate` — **генерировать**
- `verify` — **проверять**
- `use` — **использовать**

V1 используется после модальных глаголов:

- `can write` — **может писать**
- `should verify` — **следует проверить**
- `may fail` — **может ошибиться**
- `must check` — **нужно проверить**

Формула:

`modal + V1`

V1 также используется в инфинитиве с `to`:

- `to write` — **писать**
- `to verify` — **проверить / проверять**
- `to understand` — **понимать**

Формула:

`to + V1`

В Present Simple, кроме 3-го лица единственного числа:

- `I write.` — **Я пишу.**
- `They write.` — **Они пишут.**

Но:

- `He writes.` — **Он пишет.**

В Imperative:

- `Verify the source.` — **Проверь источник.**
- `Read the answer carefully.` — **Прочитай ответ внимательно.**

---

## 5. V2 — past form

**V2 = форма Past Simple.**

Примеры:

- `write → wrote`
- `generate → generated`
- `verify → verified`

Используется для действия или состояния в прошлом:

- `The model generated an answer.` — **Модель сгенерировала ответ.**
- `She wrote the report yesterday.` — **Она написала отчёт вчера.**

Для правильных глаголов V2 обычно образуется с `-ed`:

`generate → generated`

Для неправильных форма особая:

`write → wrote`

---

## 6. V3 — past participle

**V3 = Past Participle.**

Примеры:

- `write → written`
- `generate → generated`
- `see → seen`

V3 обычно не выражает прошедшее время сама по себе. Она является частью более сложной конструкции.

### Perfect

Формула:

`have + V3`

Примеры:

- `has written` — **написал / уже написал**
- `has generated` — **сгенерировал**
- `has seen` — **видел**

`The model has generated an answer.` — **Модель сгенерировала ответ.**

### Passive Voice

Формула:

`be + V3`

Примеры:

- `is written` — **написан**
- `was generated` — **был сгенерирован**
- `is verified` — **проверен / проверяется**

`The text was generated by AI.` — **Текст был сгенерирован ИИ.**

---

## 7. Главное различие V2 и V3

У правильных глаголов V2 и V3 часто выглядят одинаково:

`generate → generated → generated`

Но их функция различается.

`AI generated the text.` — **ИИ сгенерировал текст.**

Здесь `generated` = V2.

`AI has generated the text.` — **ИИ сгенерировал текст / уже сгенерировал текст.**

Здесь `generated` = V3.

`The text was generated by AI.` — **Текст был сгенерирован ИИ.**

Здесь `generated` = V3.

У неправильных глаголов различие видно формально:

`write → wrote → written`

---

## 8. Есть ли V4 и V5

Иногда в учебниках встречается схема:

- V1 = `write`
- V2 = `wrote`
- V3 = `written`
- V4 = `writing`
- V5 = `writes`

Но это **не единый международный стандарт**.

Надёжнее использовать названия:

- base form
- past form
- past participle
- -ing form
- third-person singular form

---

## 9. Форма глагола и глагольная конструкция — не одно и то же

Формы самого глагола:

`write / writes / wrote / written / writing`

Конструкции:

- `will write` — **будет писать**
- `has written` — **написал / уже написал**
- `is writing` — **пишет сейчас**
- `is written` — **написан**

То есть английский строит множество грамматических значений из небольшого числа форм.

---

## 10. Инфинитив с `to` и без `to`

Есть две близкие конструкции:

- `to write` — **to-infinitive**
- `write` — **bare infinitive**, инфинитив без `to`

### Когда используется `to + V`

После ряда глаголов:

- `want to learn` — **хотеть учиться**
- `need to verify` — **нужно проверить**
- `try to understand` — **пытаться понять**
- `plan to use` — **планировать использовать**

Для выражения цели:

- `I use AI to save time.` — **Я использую ИИ, чтобы экономить время.**
- `Read the source to verify the claim.` — **Прочитай источник, чтобы проверить утверждение.**

После прилагательных:

- `It is important to check the answer.` — **Важно проверить ответ.**
- `It is difficult to know for sure.` — **Трудно знать наверняка.**

### Когда используется V без `to`

После модальных глаголов:

- `can generate` — **может генерировать**
- `should verify` — **следует проверить**
- `may fail` — **может ошибиться**
- `must check` — **нужно проверить**
- `will respond` — **ответит**

Нельзя:

- `can to generate`
- `should to verify`

Также bare infinitive используется после:

- `let`: `Let me explain.` — **Позволь мне объяснить.**
- `make`: `It made me think.` — **Это заставило меня задуматься.**
- `help`: `help me understand` / `help me to understand` — **помоги мне понять**

---

## 11. Почему где-то есть `to`, а где-то нет

Это связано с **грамматическим управлением**.

Разные слова требуют разных форм следующего глагола.

- `I want to verify it.` — **Я хочу это проверить.**
- `I can verify it.` — **Я могу это проверить.**

Глагол один и тот же — `verify`, но:

`want → to + V`

`can → V`

---

## 12. Lexical, auxiliary и modal verbs

### Lexical verb — смысловой глагол

Несёт основное значение:

`AI generates text.` — **ИИ генерирует текст.**

`generate` — lexical verb.

### Auxiliary verb — вспомогательный глагол

Помогает строить грамматическую конструкцию.

Основные:

- `be`
- `have`
- `do`

`AI is generating text.` — **ИИ сейчас генерирует текст.**

`is` — auxiliary, `generating` — lexical verb.

`AI has generated text.` — **ИИ сгенерировал текст.**

`has` — auxiliary, `generated` — lexical verb.

### Modal verb — модальный глагол

Основные:

- `can`
- `could`
- `may`
- `might`
- `must`
- `should`
- `will`
- `would`

`AI can generate text.` — **ИИ может генерировать текст.**

`You should verify the answer.` — **Тебе следует проверить ответ.**

---

## 13. Finite и non-finite forms

### Finite verb

Форма, которая может быть центром сказуемого и связана с временем, лицом или числом.

`AI generates text.` — **ИИ генерирует текст.**

`AI generated text.` — **ИИ сгенерировал текст.**

### Non-finite form

Форма, которая сама по себе не выражает время предложения.

Основные:

- `to generate`
- `generating`
- `generated`

`AI can generate text.` — **ИИ может генерировать текст.**

`Generating text is easy.` — **Генерировать текст легко.**

`Text generated by AI may contain errors.` — **Текст, сгенерированный ИИ, может содержать ошибки.**

---

## 14. Tense, aspect и voice

Это три разных грамматических измерения.

### Tense — время

- `writes` — **пишет**
- `wrote` — **писал / написал**

### Aspect — характер протекания действия

`is writing` — **пишет сейчас / находится в процессе написания**

`has written` — **написал / уже написал**

### Voice — залог

Active:

`AI generates text.` — **ИИ генерирует текст.**

Passive:

`Text is generated by AI.` — **Текст генерируется ИИ.**

---

## 15. Transitive, intransitive и linking verbs

### Transitive verb — переходный глагол

`AI generates text.` — **ИИ генерирует текст.**

`text` — object.

### Intransitive verb — непереходный глагол

`The system failed.` — **Система дала сбой.**

### Linking verb — связочный глагол

`The answer is correct.` — **Ответ правильный.**

`It seems reliable.` — **Это кажется надёжным.**

---

## 16. Valency / complementation

Глагол определяет, какие элементы могут или должны стоять после него.

Примеры:

- `verify information` — **проверять информацию**
- `depend on data` — **зависеть от данных**
- `want to learn` — **хотеть учиться**
- `avoid making mistakes` — **избегать ошибок**
- `know what happened` — **знать, что произошло**

Поэтому глагол полезно учить не отдельно, а вместе с типичной моделью.

---

## 17. Verb phrase — глагольная группа

**Verb phrase** — группа, центром которой является глагол.

Примеры:

- `should verify` — **следует проверить**
- `has generated` — **сгенерировал**
- `is being generated` — **генерируется сейчас**
- `may have failed` — **возможно, дал сбой**

Она может состоять из нескольких глаголов, но смысловой глагол обычно один.

---

## 18. Глагол и сказуемое — не одно и то же

**Verb** — часть речи.

**Predicate / verb phrase** — синтаксическая функция или конструкция в предложении.

`You should verify the answer.` — **Тебе следует проверить ответ.**

- `should` — modal auxiliary
- `verify` — lexical verb
- `should verify` — verb phrase / сказуемое

---

## 19. Комплексный разбор

`You should verify information that is generated by AI before using it.`

**Тебе следует проверять информацию, которая генерируется ИИ, прежде чем использовать её.**

- `You` — Subject — **подлежащее**
- `should verify` — Verb phrase — **сказуемое**
- `information` — Object — **дополнение**
- `that is generated by AI` — Relative clause — **определительное придаточное**
- `is generated` = `be + V3` — Passive Voice
- `before using it` — обстоятельственная конструкция времени
- `using` — `-ing form`

Полная смысловая версия:

`before you use it` — **прежде чем ты используешь её**

Сокращённая:

`before using it` — **прежде чем использовать её**

---

## 20. Ключевые модели из корпуса текстов об AI

### Present Simple

`AI systems make mistakes.` — **Системы ИИ совершают ошибки.**

### Modal + V1

`AI can generate useful answers.` — **ИИ может генерировать полезные ответы.**

`You should verify the result.` — **Тебе следует проверить результат.**

### to + V1

`You need to check the source.` — **Тебе нужно проверить источник.**

### be + V3

`The information is generated by AI.` — **Информация генерируется ИИ.**

### have + V3

`The model has produced an answer.` — **Модель сформировала ответ.**

### V-ing

`Verify the answer before using it.` — **Проверь ответ перед тем, как использовать его.**

### Imperative

`Check the source.` — **Проверь источник.**

`Ask specific questions.` — **Задавай конкретные вопросы.**

## 21. Часто встречающиеся глаголы в обсуждаемом корпусе

| Verb | Перевод | Типичная модель |
|---|---|---|
| `be` | быть, являться | `be + adjective`, `be + V3` |
| `know` | знать | `know + clause` |
| `have` | иметь; вспомогательный | `have + V3` |
| `can` | мочь | `can + V1` |
| `ask` | спрашивать | `ask + object` |
| `verify` | проверять | `verify + object` |
| `read` | читать | `read + object` |
| `make` | делать, создавать | `make + object` |
| `follow` | следовать | `follow + object` |
| `produce` | производить, создавать | `produce + object` |
| `write` | писать | `write + object` |
| `generate` | генерировать | `generate + object` |
| `compare` | сравнивать | `compare A with B` |
| `get` | получать; становиться | `get + object / adjective` |
| `give` | давать | `give someone something` |

Примеры:

`Ask the model a specific question.` — **Задай модели конкретный вопрос.**

`Verify the information.` — **Проверь информацию.**

`Compare the answer with the source.` — **Сравни ответ с источником.**

`AI can generate text.` — **ИИ может генерировать текст.**

## 22. Компактная карта английского глагола

Полезно различать четыре уровня.

### 1. Form — форма

Например:

`written`

Это V3 / Past Participle.

### 2. Function — функция формы

V3 может использоваться в Perfect или Passive.

### 3. Construction — конструкция

`has written` — Perfect

`is written` — Passive

### 4. Role — роль глагола

Глагол может быть:

- lexical
- auxiliary
- modal

## 24. Главное для практики

Не следует учить английский глагол только как перевод отдельного слова.

Полезнее учить сразу:

**глагол + его формы + типичная конструкция + пример.**

Например:

`verify → verified → verified`

`should verify` — **следует проверить**

`need to verify` — **нужно проверить**

`verify information` — **проверять информацию**

`The information was verified.` — **Информация была проверена.**

Такой подход показывает не только значение глагола, но и то, **как он реально работает в английском предложении**.
