# RC2 — изменения относительно RC1

- По предоставленному тренером PIN сформированы случайная соль (128 бит) и PBKDF2-SHA256 verifier (256 бит, 200 000 итераций).
- В `config.json` записаны только проверочные данные, без PIN открытым текстом.
- Изменён идентификатор PWA cache (`v10-rc2`), чтобы новая конфигурация не смешивалась с ранее установленным RC1.
- Обновлены описания установки PIN, состояния проверки и выпускной информации.
- Логика измерений, модель данных, интерфейсы и формат экспорта не изменены.

Результаты фактических тестов и ограничения см. `RELEASE_REPORT.md`.
