# Interval Lab 1.2.0

Автономный мобильный секундомер для измерения серии последовательных интервалов времени, повторных упражнений и долгосрочного сравнения результатов. Интерфейс на русском языке.

## Логика измерения

При настройке **N = 10 интервалов** упражнение состоит из **11 нажатий**: первое запускает секундомер и показывает крупную цифру **0**, следующие десять закрывают интервалы и увеличивают цифру от **1** до **10**. Десятое *завершённое* измерение (11-е нажатие) останавливает часы автоматически. Длительность каждого интервала равна времени между двумя последовательными нажатиями. Сумма интервалов равна общей длительности упражнения. Первое и второе упражнения составляют пару. Пауза между ними учитывается отдельно и не включается в интервалы.

## Несколько спортсменов на одном устройстве (v1.2.0)

Кнопка с именем спортсмена в верхней части экрана секундомера открывает список профилей. Можно добавить, выбрать, переименовать или удалить спортсмена. Максимум 100 профилей; последний профиль нельзя удалить. Удаление профиля **удаляет его измерения** с дополнительным подтверждением.

**Порядок A1 → B1 → A2 → B2 поддерживается**: у спортсмена A после первого упражнения сохраняется незавершённая пара; спортсмен B может выполнить первое упражнение, пока A отдыхает. Когда вы вернётесь к A, секундомер автоматически предложит второе упражнение его собственной пары. Затем второе упражнение выполняет B. Пауза каждого спортсмена вычисляется от окончания его первого упражнения до начала второго, включая время упражнения другого спортсмена.

Во время измерения сменить спортсмена нельзя. Одновременно два секундомера не работают: измерение выполняется для одного спортсмена в данный момент, а незавершённые пары нескольких спортсменов сохраняются независимо. История и сравнение с предыдущими днями фильтруются по спортсмену. Отдельный профиль — локальная метка результатов, **не аккаунт и не контроль доступа**.

### Обновление с версии 1.1.0

Старые результаты автоматически переводятся в профиль «Спортсмен 1», включая незавершённую пару. Сохранение данных по-прежнему использует ключ `interval-lab:data:v1`, но содержимое обновляется с формата `version:1` до `version:2`. Рекомендуется экспортировать JSON перед обновлением браузера. Импорт принимает оба формата; CSV и JSON теперь содержат профили и связи с результатами. Для возврата к 1.1.0 понадобится резервная копия старого формата: она не умеет читать формат v2.

## Возможности

- Большая сенсорная область на весь экран измерения. Крупная цифра показывает **количество завершённых интервалов** (до старта — «—», после первого касания — 0). Текущее время отображается значительно мельче. При активном упражнении панель навигации скрыта; нажатия фиксируются по `pointerdown`.
- При **каждом принятом касании**, включая старт и завершение, весь фон экрана на **150 мс** становится контрастным янтарным. Отклонённые касания визуального подтверждения не получают.
- Защита от случайных повторных касаний: следующее касание принимается только когда от предыдущего **принятого** прошло **строго более 1000 мс**. Касания на границе 1000 мс также игнорируются, не влияют на измерение и не продлевают защитный интервал. После последней отсечки крупная цифра видна ещё 650 мс перед переходом к анализу.
- Настраиваемое число интервалов от 1 до 200 (по умолчанию 10). Настройка, изменённая между упражнениями, начинает действовать со следующей пары.
- Монотонные часы `performance.now()`, обновление показаний через `requestAnimationFrame`, `Wake Lock` при поддержке браузера.
- Два последовательных упражнения на каждого спортсмена, отдельный отсчёт паузы, автоматическое сохранение после каждого полностью завершённого упражнения. Несколько независимых незавершённых пар.
- График динамики интервалов, таблица по интервалам, среднее, минимум, максимум, коэффициент вариации, изменение первого и последнего интервалов.
- Графическое и численное сравнение пары; сравнение с ранее сохранёнными сеансами того же числа интервалов. По умолчанию выбирается последний сопоставимый сеанс другого дня.
- Персональная история в `localStorage`, резервный экспорт JSON, импорт JSON форматов v1/v2 с проверкой данных и без дублирования, экспорт CSV с идентификатором и именем спортсмена, явное удаление истории.
- Статические файлы без сторонних библиотек и сервера; Service Worker кеширует оболочку PWA для работы без сети после первой загрузки по HTTPS.

## Запуск

### GitHub Pages

Путь для размещения: `/interval-lab/` в репозитории `t39s/dev-sandbox`. При активном GitHub Pages, публикующем ветку `main` из корня, приложение будет доступно на `https://t39s.github.io/dev-sandbox/interval-lab/`. Статус публикации необходимо проверять отдельно.

### На компьютере без Интернета

Распакуйте архив и выполните в каталоге `interval-lab`:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000` на этом компьютере. Для доступа со смартфона в локальной сети потребуется указать IP компьютера и разрешить соответствующее подключение. Service Worker и Wake Lock на обычном HTTP по IP могут быть недоступны, но секундомер работает. Открытие `index.html` непосредственно из файлов также может работать, однако локальное хранилище при `file://` не гарантируется браузером.

### На смартфоне без Интернета

Сначала откройте опубликованный HTTPS-адрес онлайн. После полной первой загрузки и успешной установки Service Worker приложение можно открывать офлайн на этом же устройстве. На iOS для удобства выберите «На экран Домой». Переключение браузера, очистка сайта или приватный режим могут привести к потере локальной истории.

## Конфиденциальность и пределы

Измерения **не загружаются на GitHub**: GitHub хранит только исходные файлы приложения. История сохраняется отдельно в каждом браузере на каждом устройстве. Резервный JSON критичен для переноса и восстановления.

Точность зависит от аппаратуры, браузера, частоты сенсорных событий и активности вкладки. Отсчёт не сертифицирован и не предназначен для высокоточных спортивных измерений. Если вкладка перезагружена во время измерения, незавершённое упражнение не сохраняется. В фоне ОС может приостановить вкладку и Wake Lock.

## Проверка

```bash
node --test tests/*.test.cjs
```

Тестами проверяются независимые пары A1/B1/A2/B2, миграция v1, импорт/экспорт профилей, а также семантика 10 интервалов = 11 нажатий, защита «строго > 1000 мс», подтверждающая вспышка, последний кадр с цифрой 10, статистика, валидация и полный цикл двух упражнений через имитацию DOM. Для браузерных тестов с Chromium/Playwright выполните `python tests/browser_check.py` и `python tests/browser_athletes_check.py`. В тестовом окружении HTTP-навигация Chromium заблокирована; скрипт автоматически переключается на инъекцию локальных файлов в DOM. Такой режим проверяет внешний вид и поведение браузерного интерфейса, но не проверяет HTTP, работу Service Worker или офлайн-запуск.
