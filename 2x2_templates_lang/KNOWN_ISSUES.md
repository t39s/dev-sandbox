# Known issues / acceptance gaps — 2x2 0.1.0-rc.1

Это единый перечень известных ограничений RC на дату 2026-09-19.

| ID | Состояние | Риск | Описание | Решение для RC |
|---|---|---|---|---|
| KI-001 | Acceptance pending | High for final release | Реальный Safari на физическом iPhone/iPad не проверен. Эмуляция/Chromium не заменяет эту приёмку. | Допустимо для RC; **блокирует объявление финального 0.1.0**. Выполнить `ACCEPTANCE_IPHONE.md`. |
| KI-002 | Acceptance pending | Medium | Предельные 100k/500k пулы измерены в desktop/headless Chromium, но не на целевом iPhone. | Допустимо для RC; до final подтвердить на устройстве либо снизить лимиты. |
| KI-003 | Known limitation | Low–Medium | Browser runtime выполняет собственную структурную проверку, согласованную с поставляемой JSON Schema; сама JSON Schema отдельно валидируется, но библиотека общего JSON-Schema-валидатора в runtime не встроена. | ACCEPT для RC. Перед final решить, требуется ли принципиально исполнять именно Schema engine. |
| KI-004 | Product research gap | Medium | Понятность JSON и языка ограничений реальным учителем не проверена; это исходная гипотеза архитектурного исследования. | DEFER: отдельная продуктовая проверка после технической приёмки. |
| KI-005 | Known limitation | Low | Runtime-валидатор сообщает первую найденную структурную/семантическую ошибку, а не агрегирует все ошибки файла за один проход. | ACCEPT для RC; улучшение teacher UX после приёмки. |
| KI-006 | Test-environment limitation | Low | В текущей среде Chromium navigation к localhost/file URL блокируется административной политикой. E2E выполняется в реальном Chromium с инъекцией неизменённых static assets и loader/storage test doubles; отдельный HTTP smoke подтверждает отдачу файлов. | ACCEPT для RC; физическая HTTPS-приёмка закрывает этот пробел. |

Новых известных дефектов, нарушающих целостность результата упражнения, после стабилизационного цикла не осталось.
