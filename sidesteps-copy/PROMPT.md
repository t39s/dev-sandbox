# Промпт повторной реализации SideSteps

Передайте этот текст и полный файл BEHAVIOR.md одним сообщением в новой сессии.

> Создай самостоятельное браузерное приложение по приложенной спецификации BEHAVIOR.md. Пиши реализацию с нуля. Используй спецификацию как единственный источник требований. Приложение должно запускаться со статического HTTPS-хостинга из произвольного подкаталога и работать без сервера. Целевой вид — Safari на iPhone 12 mini в портретной ориентации. Реализуй все сценарии нового пользователя, перечисленные в спецификации. Для каждого экземпляра используй отдельное локальное хранилище.
>
> За один проход сделай приложение, прогони перечисленные сценарии приёмки и верни запускаемые файлы и короткий отчёт «сценарий → результат». Для неполностью наблюдавшихся деталей прими обратимые решения, согласованные с описанием, и укажи их. Не обращайся к исходникам оригинала, опубликованному оригиналу или предыдущим реализациям. Считай результат успешным, только если первый представленный вариант проходит все сценарии приёмки без уточнений и дополнительных промптов. Раздельно отметь программную проверку, проверку в браузере и проверку на физическом устройстве.
