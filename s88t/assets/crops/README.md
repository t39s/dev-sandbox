# Графические фрагменты сборника s88t

Визуальные фрагменты страниц находятся в отдельных самодостаточных SVG. В каждом SVG встроен исходный JPEG-растр страницы, а атрибут `viewBox` **обрезает видимую область**. Поэтому размер такого файла больше, чем при физической обрезке JPEG. Оптимизация байтов допустима следующим этапом без изменения отображаемого содержания.

Координаты `viewBox` заданы в пикселях исходной страницы 1013 × 1432.
