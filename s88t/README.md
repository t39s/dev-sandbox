## Принципы публикации

Первая редакция Markdown создана по PDF без исправления орфографии, пунктуации, терминологии и фактических ошибок оригинала. Сохранены исходная последовательность страниц, заголовки, текст и подписи; изменены только переносы строк, абзацное оформление и разметка заголовков. Номера печатных страниц заменены невидимыми комментариями с указанием страниц оригинала.

**Ограничение:** графические материалы (фотографии, схемы тренировочных упражнений и диаграммы) не включены в репозиторий в виде изображений. Их следует смотреть в [PDF-оригинале](https://old.ttfr.ru/docum/2013/metod_sbornik_1.pdf); текстовые подписи и доступные для извлечения надписи сохранены в Markdown. Дословность относится к тексту PDF, а не к визуальной идентичности страниц.

Исправление обнаруженных ошибок должно выполняться отдельным следующим коммитом, без переписывания истории первоначальной транскрипции.
