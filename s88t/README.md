# Особенности обучения технике и тактике настольного тенниса в КНР

Сборник методических материалов № 1. Федерация настольного тенниса России. Москва, 2011. 49 с.

[Читать интерактивную веб-версию](https://t39s.github.io/dev-sandbox/s88t/) · [Markdown-источник](./index.md) · [Оригинальный PDF](https://old.ttfr.ru/docum/2013/metod_sbornik_1.pdf) · [Редакторские исправления](./EDITORIAL_CHANGES.md)

## Архитектура

- **Единый редактируемый источник содержания:** `index.md`. Текст, заголовки и ссылки на иллюстрации редактируются в нём; оригинальные заголовки в этом файле не изменены.
- **Интерактивная публикация:** GitHub Pages/Jekyll формирует веб-представление из Markdown по шаблону `../_layouts/s88t.html`. HTML не содержит второй копии исходного текста. CSS/JavaScript задают разбиение на экраны и элементы взаимодействия.
- **Машиночитаемое представление:** тот же `index.md`. Отдельный `semantic.md` не требуется, пока не определено иное семантическое содержание.
- **Графика:** отдельные SVG-фрагменты в `assets/crops/`, полученные из оригинальных страниц. [Описание кропов и координат](./assets/crops/README.md).

## Пользовательский интерфейс

Веб-версия разработана по принципам ранее опубликованного интерактивного материала `c07a`, с вертикальной компоновкой.

- **Постоянный компактный хедер:** кнопка «☰ Оглавление» открывает панель поверх текущего экрана. Название «Сборник» возвращает на главную.
- **Иерархическое оглавление:** четыре статьи, раскрываемые подразделы; упражнения присутствуют только во второй статье и доступны через соответствующие приложения. Названия в UI показываются в обычном регистре, даже если в печатном источнике они набраны прописными буквами.
- **Главный экран:** карточки четырёх статей и сворачиваемый раздел с исходными издательскими сведениями.
- **Чтение:** материал разбит по исходным смысловым заголовкам (а заключительная статья также по страницам с диаграммами) на последовательные экраны с кнопками «Назад» / «Далее». Текст текущего экрана прокручивается вертикально, но весь сборник не выведен одной длинной страницей.
- **Упражнения:** в приложениях 1 и 2 второй статьи находятся 15 карточек. Каждая открывает режим фокусированного просмотра: схема занимает верхнюю треть доступной высоты, под ней текст описания в отдельной прокручиваемой области. Внизу постоянно доступны «Назад» / «Далее». Кнопка «К статье» возвращает к соответствующему приложению.
- **Одна вертикальная колонка:** нет двухколоночной компоновки, нет выделенного глобального раздела «Упражнения» в хедере и нет отдельной постоянно видимой кнопки запуска режима упражнений.
- **Ссылки на состояния:** `#article-2-section-2` — подраздел, `#exercise-a2-3` — упражнение. Поддерживается история браузера.
